## 验证范围与判据

- 只复制已有2048单元网格拓扑和字典；没有读旧物理场、生成网格或运行案例。两个手工制造的对称正定图压力系统各含5632内部面/1024边界面，系数用二进制可精确表示的分数，已知精确解为`1/4+(cell%11)/32`；原始初值为0。
- 参考有效例用零梯度边界，参考无效例用固定值边界且边界系数随面变化。原生`fvMatrix::setReference`对对角/源项的实际修改（或不修改）与独立期望逐位相同；非耦合边界对角/源项完整叠加，精确解的真实Ax-b为0。
- 两完整二进制往返及解文件往返逐位相同；10个坏魔数/截断/架构标记/尾部数据/过大长度负例均拒绝，已有文件禁止覆盖。独立Python解码器检查所有字段、地址、边界、参考及系数。
- 原生PCG/DIC保持tolerance=1e-7、relTol=0.05或0、默认minIter=0/maxIter=1000。四组原生fvMatrix与离线lduMatrix的解逐位相同，初/终残差与迭代数完全相等；12组策略/规则的重复解逐位相同，共32次纯线性代数求解，不是CFD。
- 原始0初值、常数0.5初值、大偏置1e6初值分别按两规则测试。大偏置是安全负例，不是推荐策略；未用这些合成样本训练或证明泛化。压力矩阵/源项在替换初值时保持不变。

原生归一化为`N(x0)=sum(|A*x0-rowSum(A)*mean(x0)|+|b-rowSum(A)*mean(x0)|)+1e-20`。替换初值没有改变字典或判据形式，却改变N及其对应的未归一化残差门槛；连“绝对tolerance”也是针对归一化残差。8个替代初值的N均发生变化。

因此固定使用**原始初值**的N及初始残差，要求重新计算的`||b-A*x||1/N(original_x0) < max(1e-7, relTol*r_initial_original)`；严格小于，等于不合格。本轮直接调用原生normFactor核对公式，并测试绝对/相对门槛等于与紧邻小于的四个边界情况。没有修改任何原生停止条件或容差。

独立Python用math.fsum稀疏行计算核验真实残差，并用基于机器精度/算子幅度的舍入误差区间认证：整个区间必须位于原固定门槛的同一侧。该区间只判断独立计算是否一致，**不放宽求解容差或接收边界**。

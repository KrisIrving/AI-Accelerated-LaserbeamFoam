# 单项mag缓存：非CFD筛选否决

2026-10-18；DEC-016 / EXP-012；起点`b6da08f1c9d0dd8af793fba4581ac2405d3938b5`。最终 **NO_BENEFIT**：原生场运算正确性在本测试范围内PASS，但候选明显不足以支持约2%的M1 solver收益筛选目标。**已停止；零新增CFD，没有运行S、M1 OFF或M1 ON，没有构建优化求解器。** 原版和数值标准不变，不开发AI，不继续投入本候选。

## 实际测试范围

独立原生OpenFOAM v2512字段工具只读取复制的M1网格和0–10 μs共11个既有alpha.metal快照，用fvc::grad及原生边界修正重建gradAlpha；另加一个内部/patch非均匀synthetic向量场。每个样本32000单元、6400边界值。没有推进Time、组装/求解方程或写场。

每样本首次用原生mag构造独立拥有存储的缓存，后续8次命中；9轮变化的thermalDamper分别比较完整原表达式mag(gradAlpha)*thermalDamper与只读缓存乘法。**12样本、108次乘积**内部/patch逐字节相同，dimensions、orientation、patch类型/大小一致；缓存及输入gradAlpha在临时量构造/析构、重复乘法后逐字节未变。每样本重新创建缓存，缓存不注册、NO_WRITE、没有泄漏到mesh registry；复制案例文件前后SHA相同。

这验证了所测原生字段、边界及tmp生命周期中的缓存做法，**不是完整M1求解轨迹等价验证**。S原生无缓存复用命中，因此本轮先做独立命中测试；因收益门槛否决，后续S/190场/30 uniform/事件检查均未启动，不冒充已经通过。

## 测得完整运算成本

同一原生工具/优化编译，CPU0、数值库线程1。每样本/模式/操作5批：hot每批256次、扰动模式每批32次，合360条批记录、51840次字段运算，其中17280次完整mag。

计时包括字段创建/分配、内部与patch运算、局部边界处理、析构及一次volatile结果读取，chrono开销未扣除；完整乘积也保留原生临时量路径。扰动模式每次测量前遍历128 MiB缓冲区（约为观察到末级缓存的3.58倍），扰动耗时排除在运算区间外。它是缓存扰动测试，不是硬件冷缓存保证或随机化微基准。

## 预先声明的停止判据

在运行前DEC-016记录：取所有样本/冷热批次的**最大完整mag批均值，再乘2倍安全系数及全部7244次**；比实际只能避免6244次更宽松，也假设缓存全部免费。若这个经验性保守尺度仍低于205.96秒的2%=4.1192秒，则停止，不运行CFD。

本次最大批均值来自3 μs梯度、扰动模式：32次总计4368031 ns，**136500.96875 ns/次**。

- 2×7244×136500.96875 ns = **1.97762603525秒**，仅205.96秒的 **0.9602%**，不到2%目标的一半。
- 只按实际可避免6244次、尚未扣缓存维护成本的最大批均值外推为0.852312秒；这也只是运算尺度外推，不是实测solver加速。
- 不把T_OTHER的30.805863秒/15.03%算为可加速份额。该阶段其余源项/控制/析构仍需执行。

因此触发 **NO_BENEFIT**，无需消耗完整CFD预算。此标签针对“约2%solver收益值得继续”的目标，**不表示数学证明任何情况下收益均为零**。微基准不能严格上界全部CFD内缓存/分配/频率行为；2倍安全系数、11个保存状态和synthetic/扰动覆盖是本机筛选证据，不是跨机器保证。没有OFF/ON CFD配对，也没有统计显著加速结论。若将来目标/场景改变，必须另行授权，不能本轮自动扩大试验。

## 1. 充分界的推导与适用范围

对冻结C、内部Gamma消元后的`H(T)=F_E(T,Gamma(T);C)`，令`g_i=Gamma'_i`：严格糊状为`1/Delta_i`，纯相及原选阈点外侧为0。写所选广义Jacobian为`J=D+E`，原工具`numerics.py:69–83`对应：

```text
D_i = V_i(c_old,i + L_i*rho_i*g_i)/dt − S'_i(T),
E = K_Tconv + K_orth + K_nonorth + K_latent-conv,
q_i = q_Tconv,i + q_diff,i + q_latent-conv,i,
m_i = D_i − q_i,  |(Ev)_i| ≤ q_i ||v||_infinity.
```

假设静态有效网格、正V/dt/物性、0≤面插值权≤1、原边界及冻结量不变。v2512 `basicFvGeometryScheme::weights`用非负距离比或1/2，支持此权重假设。若所有m_i>0，取`|v_k|=||v||∞`，则`|(Jv)_k|≥m_k||v||∞`。故J可逆，且对**这个固定线性算子**：

```text
||J^-1||_infinity ≤ 1/min_i(m_i),
Jv=b  =>  ||v||_infinity ≤ max_i |b_i|/m_i.
```

这是三角不等式/对角占优型充分证明，无需SPD。与[Varah 1975，DOI 10.1016/0024-3795(75)90112-3](https://doi.org/10.1016/0024-3795(75)90112-3)的逆范数界思路一致；本处逐行证明针对代码的更粗D/E分解。m≤0只表示该证明不能启动，**不推出真实J奇异、病态或H无根**。已保存两起点最小m为−6.33779455e-4/−6.33778944e-4 W/K，未保存最坏行的分项界，不能仅凭这两个数确定主导项或实际条件数。

## 2. 过度保守性及未建立的根误差证明

**可以符号证明损失，不必新算原场。** 两单元正交扩散系数a>0、质量系数mu>0时，`J=[[mu+a,−a],[−a,mu+a]]`的特征值是mu、mu+2a，实际对角占优裕量为mu；当前分解却给`m=mu−2a`，在`0<mu<2a`时误失认证。这是完整扩散被当作扰动、丢掉有利对角的严格反例，不是实际M1谱计算。

对流与连续性Sp本有owner/通量抵消，先取绝对值会丢失它；非正交项采用`abs(B)*abs(C)`包络而不是合成后`abs(B*C)`，也会丢失共享单元和面方向抵消。两者可证明不比保留符号的合成界紧，但**当前记录不能量化这些损失对M1负最小裕量各占多少**。未检查原场新矩阵或运行新Jv。

右预条件对角`P_i=D_i+sum_f a_f`在代码中独立构造，**没有进入m公式**；guard先因m为负退出，未执行`J*P^-1`的GMRES。因此不能把失败归因于预条件效果，也不能从负m断言P无效。换成预条件变量还须转换误差范数，不能借缩放改变原验收标准。

另有两个须在未来协议中补足的逻辑缺口（原endpoint没有执行，不影响EXP-026负结果）：

- `run_once.py:171–175`把点态`max((abs(F)+roundoff)/m)`称为终点温度误差。它至多界定当前线性Newton修正；没有邻域内的导数控制及根存在证明，不能界定到真实非线性根的距离。阈点只选一个g，也不能证明邻域内所有广义Jacobian都正则。
- A终点未必精确满足`e=Gamma(T)`，而该J属于H。精确有`H(T)=F_E(T,e)+B_phi*(Gamma(T)−e)`，`B_phi=diag(L)[diag(V*rho/dt)+Div(rhoPhi,I(.))]`，patch增量为0。使用F_E而遗漏此项，不能认证消元根误差；即使相分数差≤1e-8，潜热质量系数也可能放大它。未来须直接验证H或严格计入此项，不能只更名旧指标。

## 3. 联合Phi为何拒绝阻尼G

原`Phi=(sum_i[(F_E,i/s_i)^2]+sum_i[R_phi,i^2])/N`为无量纲；两组分量分别平方后求和，s为入口固定能量尺度。温度尺度S_T用于场差验收，未进入Phi。两组等权不是按2e-9/1e-8验收容差归一化，均方下降也不保证逐单元最大范数、全局能量预算、边界或相变/温度缺陷合格。内部未触clip且处于糊状时，`R_phi=beta*Delta*(e−Gamma(T))`，空间变化的beta*Delta也改变隐含相变权重；零beta patch不能用这个merit认证内部相变关系。

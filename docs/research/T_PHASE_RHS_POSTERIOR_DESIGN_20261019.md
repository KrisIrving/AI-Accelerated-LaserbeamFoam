## 1. RHS_ARITHMETIC_DIAGNOSIS_DESIGN：条件协议，归因尚未证明

[EXP-028](../validation/T_PHASE_NEWTON_DIRECTION_20261019.md)的终态固定原生RHS L1为**0.23875858569877612 W**；原生真实残差加舍入2.52826e-12，独立逐面路径2.21598e-9；两RHS差L1 **5.288935276734949e-10 W**，超过原绝对门槛**2.3875858569877614e-10 W**。原生PASS、独立FAIL及整体INCONCLUSIVE保留。此处RHS指Newton的H向量，不是单独的热矩阵源b。

| 项目 | 精确算术对应关系；binary64差异与待证项 |
| --- | --- |
| Euler与Sp | 静态网格`ddt(c,T)−Sp(ddt(c),T)`合并为`V*c_old*(T−T_old)/dt`。原生先形成当前质量对角、旧层源和Sp再做Ax−b；逐面先作T差，抵消顺序不同 |
| 对流、潜热 | 温度为`Div(h,upwind T)−T Div(h)`；潜热为`L*[V*(rho*e−rho_old*e_old)/dt+Div(rhoPhi,I(e))]`。L在Div外；不能删掉变L内面贡献。原生fvc先除V/乘dt倒数、再乘L/回乘V；逐面分组及owner/neighbour累加不同 |
| 非正交扩散 | 相同插值、Gauss梯度及corrected通量下，正交矩阵加显式修正等于逐面通量散度。原生`V*div(correction)`进入源，逐面直接面求和；magSf、插值权、梯度和累加的派生舍入须逐项追溯 |
| 边界 | 原T zeroGradient；epsilon calculated保持捕获patch，不能施加内部Gamma。矩阵patch内部系数加对角、边界系数加源；NumPy bincount与原生按patch/face累加次序不同。零梯度不表示对流或潜热边界贡献为零 |
| 热源 | 原生辐射隐式`4*SB*em*T^3*T`与显式`SB*em*(Tref^4+3*T^4)`相消，逐面直接`SB*em*(Tref^4−T^4)`；em入口冻结。蒸发exp/pow与sqrt、阻尼多项式、沉积/Joule及V乘法也须纳入同一算术图 |

## 2. NONLINEAR_POSTERIOR_CERTIFICATE_DESIGN：理论条件明确，32k实施NOT_READY

原问题仍为`H(T)=F_E(T,Gamma(T);C)=0`；只消元内部液相率，原patch、旧层及入口物性不变。取固定线性近似逆B（单位K/W）、正半径向量r（K），`D_r=diag(r)`，凸闭盒`X=T0+D_r*[-1,1]^N`。需要定向上界：

```text
eta ≥ norm_inf(D_r^-1 * B * H(T0))，含中心算术误差；
q ≥ sup_{T∈X, J∈J_all(X)} norm_inf(D_r^-1*(I−B*J)*D_r)；
q < 1，eta + q ≤ 1。
```

`J_all(X)`须包含盒内全部允许广义Jacobian及线段斜率的凸包：跨Ts/Tl者Gamma斜率包住`[0,1/Delta]`，不能沿用点态单侧0；包括完整非正交扩展耦合、Euler/Sp、潜热输运及辐射/蒸发/阻尼导数。须证明T严格正、分母不含0、源项有限，内部Gamma在[0,1]；T patch随owner更新，epsilon patch及旧层固定，beta_patch=0不能增加内部相变约束。

若这些包络成立，沿线段积分可证`T−B H(T)`在X上压缩且自映射，故有X内唯一固定点；`q<1`又使方阵B满秩，故固定点确为H的根。后验温度误差受r约束，相分数误差由Gamma的Lipschitz界及区间传播给出；不推出全局唯一或物理真值。即使包含成立，仍须分别检查原固定s能量2e-9、相变1e-8、边界/全局预算等合同；大误差盒不能冒充高精度参考，原S_T及P_ref不变。这是覆盖clip斜率后的条件论证，不能直接套用要求连续可微的[Rump 2010，§13/定理13.3，DOI 10.1017/S096249291000005X](https://www.tuhh.de/ti3/rump/intlab/ActaNumerica2010.pdf)。

未消元候选必须用`H(T)=F_E(T,e)+B_phi*(Gamma(T)−e)`，其中`B_phi=diag(L)[diag(V*rho/dt)+Div(rhoPhi,I(.))]`，patch增量0。相分数误差经潜热放大后必须进入中心包络，不能只检查1e-8。B的存储/应用误差、稀疏截断、线性解误差和源项舍入须进入eta/q；可用精确规定的存储系数算子B并验证应用误差，不能把依赖RHS的有限步GMRES黑盒当作固定线性逆。

**未解决的实施缺口：** 没有已验证的近根中心、r、有限稀疏B表示、全空间`I−BJ`行和界或其计算成本。少量Jv/点态真实残差不能控制未探索方向；局部条件估计不是上界。稀疏J不保证B或乘积包络稀疏；绝对值传播可能丢掉关键抵消，跨活动集区间也可能过宽。没有证据保证32,000单元在有限填充、内存及墙钟内认证q，禁止借稠密逆解决。故本轮无法提出成本可认证的根存在性数值实验；这是证书未建立，**不是证明无根、奇异或传统算法失败**。

## 2. 要求解的是哪个离散系统

继承[原数学审查](T_PHASE_FIXED_POINT_REVIEW_20261018.md)；未知量为全部32000单元的内部T、l=epsilon1，不能只筛金属区。C固定网格/几何/patch类型和旧层，rho/cp/kappa/L、Ts/Tl、rhoPhi、c=rhoCp、h=rhophicp、gradAlpha、入口em、激光/Joule、材料与原离散字典；改变候选l不能重算入口em，改变T不能调用updateProps重算cp/kappa。派生蒸发/辐射/阻尼、当前梯度及相变源必须在同一候选状态重新评价。

以下F_E为体积积分后的每单元W残差；D_t/D_f/L_kappa严格指原Euler/有限体积算子及边界系数，非连续PDE替代：

```text
F_E(T,l;C) = D_t(c,T)+D_f(h,T)−[D_t(c)+D_f(h)]T−L_kappa(T)
           + L[D_t(rho,l)+D_f(rhoPhi,l)]−Qlaser−QJ
           − a(T){SB*em_entry*(Tref^4−T^4)−Qv(T)} = 0,
a(T)=mag(gradAlpha)*damper(T),
Qv(T)=0.82*Lv*Mm*p0*exp[Lv*Mm*(T−Tv)/(R*T*Tv)]/sqrt(2*pi*Mm*R*T).

R_phi = l−clip[l+beta*(T−Ts−DeltaT_m*l),0,1] = 0,
beta=0.9*cp/L, DeltaT_m=Tl−Ts.
```

内部beta>0、DeltaT_m>0时，R_phi=0等价于`l=Gamma(T)=clip[(T−Ts)/DeltaT_m,0,1]`：固相l=0要求T≤Ts，糊状0<l<1要求T=Ts+DeltaT_m*l，液相l=1要求T≥Tl。求解域为T>0、0≤l≤1、所有算子有限/阻尼分母有效；不另设人为温度上限，不改材料。原TEqn的relax矩阵用于G，不代替上述未松弛同态方程；在精确固定点其对角补偿抵消，有限容差G_native的停止仍与精确代数根不同。

**边界不能随内部消元改写。** 原T为zeroGradient，T_patch按原生evaluate由owner给定；l为calculated。EXP-024确认cp_patch=0，因此beta_patch=0，原clip更新在可行域内保持入口l_patch，其后calculated的evaluate不施加新的温度相分数关系。参考问题保留该原生更新/入口patch值，仍用它计算潜热边界通量，不改成另一种patch类型。Gamma只消去内部l；不能在beta=0的patch强加Gamma(T_patch)，否则增加了原版没有的方程。旧21轮相变/温度缺陷统计包含patch，本设计仍保留内部、patch及原全场最大值，不能把缩小统计域写成残差改善。patch热力学关系是额外质量验收、不是新增求根方程；若它与原边界冲突而无法满足所要求的全场精度，标BOUNDARY_THERMODYNAMIC_LIMITATION/INCONCLUSIVE，即使内部代数根存在也不冒称联合参考通过。若未来发现非零beta或其他patch语义，停止而不是自动沿用此消元。

因此可以明确定义**条件于C、含原边界的离散数值根**；尚不能证明存在、唯一、正则或代表真实物理温度。独立性来自针对同态方程及独立验算，不是把原21轮结果当标签。

## 3. 两条数学上不同的参考路线（仅设计）

共同固定`S_T=3710.4316126698473 K`和EXP-024入口逐单元能量尺度s，不按当前残差缩放。设内部全N单元的`Phi=mean[(F_E/s)^2]+mean[R_phi^2]`，边界按上节原生规则处理；最终验收另要求最大范数/全局预算，不能只最小化Phi。

| 路线 | 未来离线算法定义 | 适用条件与主要风险 |
| --- | --- | --- |
| A：受保护外层阻尼固定点 | 保留原G内部公式、smoothSolver/symGaussSeidel、tol1e-9/relTol0及epsilonRel0.9；一次G得方向G(z)−z；候选为z+omega方向。omega依次1/2、1/4、1/8、1/16、1/32，只接受可行且`Phi_trial≤(1−1e-4*omega)*Phi_base`的候选；不满足五次即停止。候选残差组装不额外调用G | 保持理想G固定点集合，但有限容差G只给近似方向；G未证压缩/非扩张，也未证是Phi下降方向。可能继续周期、停滞或所有试步被拒。小omega造成的小步长不能充当收敛；不以原周期状态作“可靠回退根” |
| B：全局化半光滑Newton | 精确消去内部l，求`H(T)=F_E(T,Gamma(T);C)=0`；保留原patch。广义Jacobian包含Euler、两类对流、非正交梯度修正、潜热Gamma导数及辐射/蒸发/阻尼导数。内部糊状Gamma'=1/DeltaT_m，纯相/阈点按预注册外侧选择0。Newton方向后作可行性回溯，最多五次（首步≤1，此后减半），要求同样的相对Phi下降 | 在正温有效域内具有分片光滑结构，但广义Jacobian非奇异性、全局收敛均未证；潜热对流/非正交项可产生更宽非对称耦合，不能套压力PCG或忽略这些导数。奇异/病态、活动集反复切换、非根驻点和线搜索失败均可能。仅冻结近邻矩阵作预条件，不能把它冒称完整Jacobian |

B先取可行首步`lambda0=min(1,0.99*min[-T_i/dT_i; dT_i<0])`（无负方向时为1），试探lambda0到lambda0/16，禁止事后更改搜索序列。B预注册采用解析广义Jv及有界Krylov工作（具体已有接口须在未来构建前确认），不对带容差停止的G黑盒直接求导。阈点的校验须分活动侧，不能以跨clip中心差分冒充光滑导数；不允许为通过验证事后选择导数分支。Newton辅助系统使用固定RHS尺度，要求独立真实线性相对残差加舍入预算<1e-9；它是不同矩阵，不能把原T求解器的归一化数字原封不动套上。

两者都是既有数值技术，不是算法创新：[PETSc官方SNES手册](https://petsc.org/release/manual/snes/)列出阻尼Richardson、Newton线搜索/信赖域及内层精度控制；这里只据此核实方法类别，不选定或安装PETSc。[Hintermüller–Ito–Kunisch，DOI 10.1137/S1052623401383558](https://doi.org/10.1137/S1052623401383558)讨论特定互补问题的活动集/半光滑Newton关系，不提供本热系统收敛定理。[Benson–Munson作者稿§3](https://www.mcs.anl.gov/~tmunson/papers/semismooth.pdf)给出互补残差及merit线搜索，也明确某些方向并无下降保证；全局化不等于保证求得根。

全局预算的P_ref分组也须固定：静态Euler的储能项合并为`V*c_old*(T−T_old)/dt`，另分`D_f(h,T)−T*D_f(h)`、扩散、当前潜热项和总热源；P_ref取入口这五组各自L1之和与1 W的较大者。禁止把代数上可抵消的大项任意拆开来放大分母。预算展开仍核对原Sp修正及变L内部通量，不能擅改原离散守恒性质。

**预注册顺序：** 未来实施前冻结完整C/ABI/源码SHA、上述候选数字/单位/尺度、制造状态和独立热源、负例、单侧扰动方向与两步长、导数/线搜索规则、种子、计数/截止及失败标签；负责人批准后先校准，再运行四分支。制造源从指定离散状态独立计算，不拟合原生输出。若噪声、已知根误差或原线性容差不能支持目标，记CALIBRATION_FAILED/INCONCLUSIVE并停止，不用`max(旧门槛,噪声)`自动放宽，不看结果后改标准。任何放宽/更换目标须另一个决策，原生产参数仍不变。即使通过，也只得到限定C与校准精度的数值参考候选，不称独立物理真值。

## 5. 唯一最小受控离线实验提案（未批准执行）

一次新批次、一个既有738步C、两个方法×两个种子，共四分支；再少就缺少所要求的跨路线或初值证据。先核对EXP-024哨兵/边界/残差接口及24次以内的校准R评价（已知根3次、六方向两步长12次、负例3次、入口/旧双状态及重载复核6次）。未来最多一次隔离构建；已有工具链无法表达完整Jv/所需非对称Krylov接口时，技术INCONCLUSIVE，不安装或扩大平台。本轮不编写这些工具或算法。

预先规定停止：校准/保护/接口/恢复失败或非法已接受状态停止全批；总截止/计数到限也停止全批。某路线原生线性失败、辅助Krylov未达标、五次回溯均拒绝或达到该分支步数上限，停止该分支并归档，不重试；结构仍可信且预算允许时，只可按原计划完成剩余独立分支一次，整体验收仍为INCONCLUSIVE，不能把某一路的解改充双路线参考。非有限试探只能在已计费的五次回溯中拒绝/缩步，不能裁剪数值后冒充原方程。若候选在同一切面两次重复双状态而联合残差仍超标，或活动集反复切换且连续五个接受步Phi无1%下降，也记CYCLING_OR_STAGNATION/INCONCLUSIVE，不靠极小步长宣布收敛。正常活动集变化但残差在下降并不自动判失败。

## 6. 研究价值与本轮保护
